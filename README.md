# Mein Budget 2026

Ein persönlicher Budget Tracker als einzelne HTML Datei.

## Benutzung

`MeinBudget2026.html` im Browser öffnen (am Handy z.B. in Safari). Pro Monat lassen sich Ausgaben je Kategorie eintragen, das Monatsbudget je Kategorie anpassen und unter "Verlauf" die letzten Monate vergleichen.

## Wo die Daten liegen

Die eingetragenen Werte werden im Speicher des Browsers abgelegt (localStorage), nicht in dieser Datei und nicht auf GitHub. Sie bleiben also nur in dem Browser auf dem Gerät erhalten, in dem sie eingetragen wurden.
